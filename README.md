# 领猫智慧供应链实践库

让企业用好 AI Agent，把供应链经验转化为可复用的经营能力。

本项目面向领猫 SCM 用户、企业内部业务负责人和贡献者，逐步整理接入指南、业务知识、实用场景与经过验证的工具，服务于款准时上市、货准时交付、财算得清。

## 当前状态

项目已初始化，正在建设首批内容。当前仓库尚未提供可执行的 SCM 自动接入、技能安装、问题代提交或经验自动上传服务。

请勿将规划中的能力视为已经上线的功能。后续接入指南将明确适用版本、前置条件、授权范围与验证方法。

## 建设方向

- **接入指南**：引导 Agent 检查环境、由用户完成授权，并进行最小只读验证。
- **业务知识**：维护术语、指标口径、流程前提与数据关联，每项内容注明依据和适用范围。
- **实用场景**：围绕研发、采购、生产、交期、库存、成本和协同，提供可复现的方法。
- **使用助手**：在支持的 SCM 使用场景中发现问题、整理反馈，帮助用户跟进处理。
- **经验贡献**：在用户明确授权后收集允许分享的经验摘要，经复现与审核后公开。

## 给 AI Agent 的说明

当前请仅介绍本项目的建设范围，或协助用户整理问题与贡献草稿。

- 不要推测接口地址、授权方式、字段含义或已支持的功能。
- 阅读本仓库不代表用户已授权安装、取数、修改业务数据或上传内容。
- 不要索取或公开密钥、原始对话、客户单据及企业敏感经营数据。
- 待接入与场景指南发布后，按用户目标读取相关内容并核对适用版本。

## 参与贡献

欢迎员工和社区贡献者通过 Pull Request 提交经过核验的内容。请先阅读 [贡献指南](CONTRIBUTING.md)。

贡献者负责说明问题、方法、适用范围和验证证据；项目负责人审核后合并。知识贡献激励将按后续公布的规则执行，当前不承诺具体金额。

## 问题反馈

有 GitHub 账号的用户，可以在 [Issues](https://github.com/IfLinkIf/lingmao-scm-playbook/issues) 提交不含敏感信息的问题。

公共 Issue 和 Pull Request 在提交时即公开，请在提交前完成脱敏。没有 GitHub 账号的用户，目前请通过已有的领猫客户服务渠道反馈；免 GitHub 账号的反馈入口仍在规划中。
